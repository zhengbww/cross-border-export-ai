# 中文版

## 项目简介

**AI 驱动的跨境出口市场机会识别与智能决策平台**是一个面向求职作品集的端到端数据分析项目。项目以 UN Comtrade 贸易数据为基础，围绕 HS850760 锂离子蓄电池，将市场数据采集、特征工程、无监督市场分群和可视化决策展示串联为完整流程。

## 项目背景

跨境出口市场选择需要同时观察市场规模、增长与活跃度等多种信号。本项目将公开贸易数据转化为结构化市场画像，以更系统地比较不同目的地市场，并追踪市场机会的变化。

## 数据来源

- **UN Comtrade API**
- **HS850760 — Lithium-ion accumulators（锂离子蓄电池）**

## 市场特征工程

项目为每个目的地市场构建可比较的特征，包括：

- **export volume**：出口规模
- **growth**：增长表现
- **momentum**：近期动量
- **stability**：稳定性
- **active market ratio**：市场活跃月份占比

这些特征共同形成市场特征矩阵，作为市场分群和机会分析的输入。

国家×月份贸易数据会先转换为国家级市场画像。针对出口规模的长尾分布使用 **log transformation**，针对低基数市场的增长波动使用 **symmetric growth metric**，并结合 momentum、stability 与 activity 等指标构建特征。

## 机器学习方法

市场不存在预先定义的“高机会”人工标签，因此项目采用 **KMeans 无监督学习**，根据市场特征之间的相似性进行分群。分群结果用于形成市场画像，并支持后续市场机会比较，而非训练一个有标签的预测模型。

### 聚类评估（Machine Learning Evaluation）

项目使用 **Elbow Method** 和 **Silhouette Score** 辅助评估不同的聚类方案，并结合聚类效果与业务解释性选择分群方案。

## Dashboard

项目使用 **Streamlit Dashboard** 展示市场画像、市场机会、机会动态以及验证与决策相关结果。Dashboard 读取 Notebook 生成的正式输出文件。

# English Version

## Project Overview

**AI-Driven Cross-Border Export Market Opportunity Identification and Intelligent Decision Platform** is an end-to-end data analysis portfolio project. Built on UN Comtrade trade data for HS850760 lithium-ion accumulators, it connects market data acquisition, feature engineering, unsupervised market segmentation, and visual decision presentation in one workflow.

## Project Background

Cross-border export market selection requires balancing signals such as market scale, growth, and activity. This project turns public trade data into structured market profiles so destination markets can be compared more systematically and changes in market opportunity can be tracked.

## Data Source

- **UN Comtrade API**
- **HS850760 — Lithium-ion accumulators**

## Technical Pipeline

    Trade Data Acquisition
          ↓
    Market Panel Construction
          ↓
    Feature Engineering
          ↓
    Feature Scaling
          ↓
    KMeans Clustering
          ↓
    Market Profiling
          ↓
    Decision Dashboard

## Market Feature Engineering

The project creates comparable features for each destination market:

- **export volume**
- **growth**
- **momentum**
- **stability**
- **active market ratio**

Together, these features form the market feature matrix used for segmentation and opportunity analysis.

Country-by-month trade data is first transformed into country-level market profiles. A **log transformation** addresses the long-tailed distribution of export volume, while a **symmetric growth metric** helps handle low-base growth volatility. Momentum, stability, and activity indicators complete the feature set.

## Machine Learning Method

Markets do not have predefined human labels for “high opportunity.” The project therefore uses **unsupervised KMeans clustering** to group markets by feature similarity. The resulting segments support market profiling and opportunity comparison; they are not the output of a supervised prediction model.

### Machine Learning Evaluation

The project uses the **Elbow Method** and **Silhouette Score** to help assess alternative clustering schemes, then selects a segmentation approach based on clustering quality and business interpretability.

## Dashboard

The **Streamlit Dashboard** presents market profiles, market opportunities, opportunity dynamics, and validation-and-decision outputs. It reads the formal files generated by the analysis Notebooks.

## Project Results

The current analysis workflow turns trade data into comparable market features and produces:

- market segments and 2024 market opportunity rankings

- trade-data validation records and a validation-and-decision results table for representative markets
- identification of mature markets, high-growth potential markets, and markets at a nurture or exploration stage
