# Export Market Intelligence Dashboard

## Product positioning

This project is a Streamlit presentation layer for an AI-driven export market opportunity and decision platform. The research subject is China’s HS850760 lithium-ion battery export market.

The Dashboard is read-only. It presents the formal analysis results already generated by the notebooks; it does not retrain KMeans, recompute Opportunity Score, modify the source data, or turn the unfinished `05_market_opportunity_showcase.ipynb` into business logic.

## Relationship with Notebooks 01–04

The Dashboard follows the formal analysis chain:

1. **Notebook 01 — Data acquisition**: retrieves China’s HS850760 export data from UN Comtrade and saves the raw, processed, and annual market data.
2. **Notebook 02 — Market segmentation and scoring**: builds market-level features, applies the existing KMeans segmentation, calculates the five score dimensions, Opportunity Score, market segment, and decision tier.
3. **Notebook 03 — Opportunity update**: applies the frozen 2023 model to 2024 data and exports score and rank changes, including the top risers.
4. **Notebook 04 — Validation and decision**: validates a small group of priority markets using the destination market’s import structure and records the final strategy, rationale, and data-risk fields.

The app consumes the CSV outputs from this chain. Notebook 05 is an unfinished showcase draft and is intentionally not used as a source of business definitions or data rules.

## Dashboard pages

1. **Global Market Opportunity** — Shows the overall 197-market opportunity landscape, KPI cards, the Top 15 ranking, the Size Score vs. Growth Score matrix, market segment distribution, and segment/tier filters.
2. **Market Explorer** — Lets users select a destination and inspect its rank, score, segment, decision tier, export value, and five score dimensions against the global average. It also makes the different opportunity sources of France and Uzbekistan directly comparable.
3. **Opportunity Dynamics** — Shows 2023-to-2024 Opportunity Score and rank movement, the Top Opportunity Risers, and the relationship between 2023 and 2024 ranks.
4. **Validation & Decision** — Covers the four markets validated in Notebook 04: France, Uzbekistan, Romania, and Serbia. It presents the model signal, import-market validation, recommended strategy, decision reason, and data-reliability checks.

## `requirements.txt`

`requirements.txt` declares the lightweight runtime dependencies needed by the Dashboard:

- `streamlit` — web application and interactive controls
- `pandas` — CSV loading and tabular display preparation
- `plotly` — interactive charts

Keeping these dependencies in one file makes installation repeatable across Windows environments. The Dashboard does not require the notebooks’ API or machine-learning packages at runtime because it reads the already-generated outputs.

## Install and start on Windows PowerShell

Run the following commands from the repository root:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app/app.py
```

If PowerShell blocks virtual-environment activation, allow it for the current process only and activate again:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

If the repository already contains `.venv`, the first command can be skipped. `streamlit run app/app.py` is also valid after the environment is activated.

The app automatically searches for the project’s `notebooks/outputs/` directory and does not use a machine-specific absolute path. If an expected file is missing or its required fields do not match, the app shows an actionable error message rather than failing silently.

## Formal data inputs

All five files below are expected under `notebooks/outputs/`:

| File | Role in the Dashboard |
|---|---|
| `market_opportunity_ranking_2024.csv` | Main 2024 ranking, five score dimensions, market segment, and decision tier. |
| `priority_export_markets_2024.csv` | Formal list of markets in the `重点候选` decision tier. |
| `market_opportunity_change_2023_2024.csv` | Comparable-market score, rank, and segment changes from 2023 to 2024. |
| `top_market_opportunity_risers_2024.csv` | Top 20 markets sorted by rank improvement. |
| `final_market_validation_decision_2024.csv` | Final validation and commercial decision table for four markets. |

The formal data chain is based on UN Comtrade trade statistics for China and, in Notebook 04, destination-market import reports for validation. The Dashboard only reads these local CSV outputs.

## Metric and display conventions

- Opportunity Score and the five dimensions are displayed on a 0–100 scale, with one decimal place.
- Monetary values use `$M` and `$B` where appropriate.
- Growth and share values are displayed as percentages.
- `share_change` is shown in percentage points because it is the difference between two China-share values.
- The Opportunity Score is read from the output file. The Dashboard does not recalculate it.

## Known data limitations

- The ranking output contains 197 markets, but Saint Kitts and Nevis and San Marino have missing Opportunity Scores. Their source output has no first-half 2024 exports, so the related momentum/score fields are incomplete; the Dashboard flags them and omits them from score-ranked charts.
- The dynamics output compares 194 markets rather than all 197 ranked markets. This follows Notebook 03’s inner join across the two annual model outputs; Bermuda, Faroe Isds, and Nauru are not present in the comparison table.
- The ranking output contains both `segment` and `market_segment`. These labels are inconsistent for 128 of 197 rows because they come from different naming stages in Notebook 02. The Dashboard uses the formal final field `market_segment` and ignores the legacy `segment` column.
- The four validated markets show material bilateral mirror differences between destination-reported imports from China and China-reported exports. Notebook 04 treats this as a data-quality and interpretation risk, not as an input to Opportunity Score; the Dashboard displays `mirror_gap_pct`, `mirror_similarity`, and `data_risk` separately.
- The model is a dynamic market segmentation and opportunity-monitoring tool, not a forecast of next year’s export value. Tariffs, logistics, policy, competition, and geopolitical risk require additional external validation.
